# RiftEater — Minecraft Forge 1.12.2

## Состав
- Босс Разломный Пожиратель: 750 HP.
- Когти: ближняя атака.
- Сгустки тёмной материи: снаряды, 14 урона и замедление.
- «Скачок разлома»: перемещение на 5–7 блоков, перезарядка 5 секунд, попытки найти безопасную точку и частицы.
- Опыт за смерть: 2450.
- Добыча: 4–8 алмазов, шанс алмазных предметов, 2–4 зачарованные книги.
- Призыв: предмет «Печать призыва разлома», применить по верхней стороне блока.
- Нет естественного спавна.

## Сборка
GitHub Actions собирает проект при push в `main`/`master` или вручную через Actions → Build RiftEater → Run workflow.
Скачай JAR в Actions → успешный запуск → Artifacts → RiftEater-1.12.2.

## Установка
Положи `RiftEater-1.0.0.jar` в папку `.minecraft/mods` вместе с Forge 1.12.2.

## Призыв
В творческом режиме найди «Печать призыва разлома» во вкладке Rift Eater. В выживании предмет пока предполагается выдавать через творческий режим/команду; рецепт добавим отдельно.

## Важно
Этот ZIP — исходный проект для облачной сборки, а не готовый JAR. Для полноценной уникальной внешности потребуется заменить временную модель/текстуру.
